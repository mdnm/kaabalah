# Astrology research addendum: cross-module search including NOTAS

Status: phase1 research, not description drafting. Mat selected paragraph format and requested maximum fidelity. The original instruction that NOTAS is context only remains in force: searching and recording a location is separate from quoting or paraphrasing it into a library entry. This addendum contains topic labels and evidence locations, no copied private-note bodies or client identities.

## What was checked

The first pass read all23 module4 classes through EOF, including NOTAS for context. It did not use NOTAS as description evidence. The second pass searched all115 original class Markdown files under modules1-5,97,985 logical lines, by planet, sign, aspect, additional-point and technique names. Matching was accent-insensitive and included common spelling variants and adjective/plural forms. This is a keyword search with targeted surrounding-passage inspection, not a claim to have fully read all115 classes.

NOTAS boundaries include standalone `NOTAS:` without Markdown hashes, as well as Markdown headings. This matters in modules1-3, where a heading-only detector incorrectly labels private notes as handout text. Classification was corrected before saving results. Two files had no standalone NOTAS boundary (module1 class7, module2 class3); this establishes only the absence of that marker, not the public eligibility of every sentence.

[Search ledger](astrology-inventory-notes-search.json) records hashes,115 file paths, boundaries, exact search patterns and526 matching NOTAS line locations with matched terms. It stores no source-note bodies. There are8,594 matching lines overall; counts below are search matches, not distinct teachings or approved entries. False positives include musical `sol`, mythic animals, ordinary grammatical conjunction/opposition, and `ISCHIRON` in a ritual name.

## Editorial decision recorded

Paragraph format is selected. Preserve the source's actual emphasis, qualifications and paired strengths/tensions. Portuguese first, equivalent English second. No fixed length should force filler, erase a qualification or invent balancing material absent from the teaching. Two short sentences and keywords remain a flexible proposal, not an instruction to distort a richer or thinner source. Practices, private identities and promised outcomes remain outside the requested factor descriptions.

Scope/order approval remains pending. This search does not begin phase2. No library source, API, tests, commit or publication was changed by this addendum.
