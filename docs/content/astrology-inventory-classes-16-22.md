- Class notes is visibly a large included book text, naming Alexandre Volguine and appended Maurice Froger/Maurice Privat. Treating the class and that book tradition as independent agreement would overstate corroboration.
- Annual retrogrades: class notes:3478-3491 emphasizes delay and prior states; the quoted Gouchon/Reverchon rules at class notes:5994-6003 specifically reject a malevolent character for Mercury/Venus retrograde. Preserve these as a review issue if annual-retrograde text enters scope.
- Solar-return location: main author insists on actual return location at class notes:231-250; appended sidereal-return author questions it at class notes:6722-6738. These are distinct techniques and cannot silently become one claim.
- Astrology decan computation currently uses Chaldean planet rulers and Golden Dawn tarot (`src/astrology/decans.ts:1-39`). Class notes:6908-6922 supplies Tree sphere assignments by modality and degree band. They share divisions but not meaning or authority.
- Class notes:141-144 explicitly warns that Priapus is not always exactly opposite Lilith. A consumer API must not invent this point by opposition while labeling it the same calculation without an approved convention.
- Class notes:667-670 calls Capricorn masculine. Flag against the main class sign tables before synthesizing gender/polarity metadata; do not let one copied profile override a complete sign system.
- The source has deterministic illness, mortality, fidelity and sexuality claims throughout. Eligible inventory records their presence; proposed consumer texts must honor the task's explicit no health/relationship outcome predictions. No practices or rituals become descriptions.
- The Chinese material contains self-conflicts (for example, dog-dog incompatibility in class notes:142-147 versus dog compatibility including dog at class notes:723). Its claims about Western astrology at class notes:165-189 are also inconsistent with the Western source framework. Keep Chinese material separate for Mat's decision rather than importing equivalences.
- Class notes:6844-6900 contains book advertisements/blurbs. Titles such as progression, hemispheres, intercepted signs, dignities and aspects listed there are not actual teaching sections or evidence for factor descriptions.
