## Installation

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install kaabalah
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm install kaabalah
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add kaabalah
    ```
  </TabItem>
</Tabs>
