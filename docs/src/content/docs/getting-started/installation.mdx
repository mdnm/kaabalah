## Installation

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install kaabalah
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm install kaabalah
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add kaabalah
    ```
  </TabItem>
</Tabs>

## Module imports

Each module can be imported independently, keeping your bundle lean:

```typescript
import { calculateKaabalisticLifePath } from 'kaabalah/numerology';
import { calculateGematria } from 'kaabalah/gematria';
import { ARKANNUS, shuffleTarotDeck } from 'kaabalah/tarot';
import { createTree } from 'kaabalah/core';
import { calculateOdu } from 'kaabalah/ifa';
import { getTarotThemeProfile } from 'kaabalah/semantic';
import { generateTreeSvg } from 'kaabalah/visual';
```

## Astrology module — WebAssembly requirement

<Aside type="caution">
`kaabalah/astrology` uses Swiss Ephemeris compiled to WebAssembly. It is the only module that requires additional setup.

All other modules (`numerology`, `gematria`, `tarot`, `core`, `ifa`, `semantic`, `visual`) are pure TypeScript with no native dependencies.
</Aside>
