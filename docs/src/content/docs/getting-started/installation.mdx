## Installation

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install kaabalah
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm install kaabalah
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add kaabalah
    ```
  </TabItem>
</Tabs>

## Module imports

Each module can be imported independently, keeping your bundle lean:

```typescript
import { calculateKaabalisticLifePath } from 'kaabalah/numerology';
import { calculateGematria } from 'kaabalah/gematria';
import { ARKANNUS, shuffleTarotDeck } from 'kaabalah/tarot';
import { getIChingReading } from 'kaabalah/iching';
import { createTree } from 'kaabalah/core';
import { calculateOdu } from 'kaabalah/ifa';
import { getMayaCalendarDay } from 'kaabalah/maya';
import { generateTattwaSvg } from 'kaabalah/tattwa';
import { getTarotThemeProfile } from 'kaabalah/semantic';
import { generateTreeSvg } from 'kaabalah/visual';
```

## WebAssembly requirements

<Aside type="caution">
`kaabalah/astrology` uses Swiss Ephemeris compiled to WebAssembly. The Maya birth-cycle and sunset calculations and the location-based Tattwa schedule also use Swiss Ephemeris. Date-only Maya calculations, Tattwa schedules computed from supplied sunrise times, and Tattwa SVG generation run without initializing it.
</Aside>
