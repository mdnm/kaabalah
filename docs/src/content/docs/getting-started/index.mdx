Kaabalah is a TypeScript library for esoteric calculations, including numerology, astrology, kabbalah, gematria, tarot, I Ching, Ifa, Maya astrology, and the Tatwameter.

## Installation

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install kaabalah
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm install kaabalah
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add kaabalah
    ```
  </TabItem>
</Tabs>

## Modules

Each module is tree-shakable and can be imported independently:

| Import path | What it provides |
|---|---|
| `kaabalah/core` | Tree of Life graph — spheres, paths, and cross-system correspondences |
| `kaabalah/numerology` | Life path, challenges, cycles, personal year calculations |
| `kaabalah/astrology` | Birth charts, synastry, composite, transits, solar returns, profections, firdaria, ACG (Swiss Ephemeris) |
| `kaabalah/gematria` | Hebrew numerology for Latin text, reverse gematria |
| `kaabalah/tarot` | 78-card deck, profiles, archetypes, correspondences, multi-deck images, spread engine |
| `kaabalah/iching` | 64 hexagrams, classical text, plain-language descriptions, Han derivations, coin casting |
| `kaabalah/ifa` | Ifa divination — Odu numbers from a date |
| [`kaabalah/maya`](/modules/maya/) | Tzolk’in, Haab, and Kenneth Johnson’s natal, timing, and relationship methods |
| [`kaabalah/tattwa`](/modules/tattwa/) | Sunrise-based Tatwameter schedules and single or nested SVG symbols |
| `kaabalah/semantic` | Occult theme profiles for NLP and search, reading connections, and Kaabalistic overlay markers |
| `kaabalah/visual` | Tree of Life and astrology wheel SVG generation, render models |

## Quick Example

```typescript
import { createTree } from 'kaabalah/core';

const tree = createTree({
  system: 'kaabalah',
  parts: ['westernAstrology', 'tarot'],
});
```
