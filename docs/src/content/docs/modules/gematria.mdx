## How Gematria Works

Latin letters are mapped to Hebrew letter values:

- Vowels (A, E, I, O, U, W, Y) have specific values
- Consonants map to Hebrew consonant values
- Position-dependent values (e.g., O at start = 70, elsewhere = 6)
- Final letter forms (sofit) when at word end

## Usage Example

```typescript
import { calculateGematria, reverseGematria } from 'kaabalah/gematria';

// Calculate gematria for a name
const result = calculateGematria('DAVID');
console.log(result.synthesis.originalSum);  // Total value
console.log(result.vowels.originalSum);     // Vowels value
console.log(result.consonants.originalSum); // Consonants value

// Find words with specific values
const matches = reverseGematria({
  targetSynthesis: 25,
  maxLength: 5
});
```

## Meaning tables

`getGematriaData(language?)` returns the three read-only meaning tables for a total: `INDIVIDUALITY_NUMBER_MEANINGS`, `PERSONALITY_NUMBER_MEANINGS` and `SYNTHESIS_NUMBER_MEANINGS`. English is the default; `'pt'` and `'pt-BR'` select Portuguese. `GEMATRIA_TEXT_DATA` holds both languages as `{ en, pt }`.

```typescript
import { getGematriaData } from 'kaabalah/gematria';

const texts = getGematriaData('pt-BR');
texts.INDIVIDUALITY_NUMBER_MEANINGS[7];
texts.PERSONALITY_NUMBER_MEANINGS[7];
texts.SYNTHESIS_NUMBER_MEANINGS[7];
```

The CLI `gematria` command returns numbers and letter correspondences only, not these texts.
